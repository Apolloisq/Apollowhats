# Apollo whatsapp 🚀
Extensión de código abierto para Google Chrome que te permite mantener la privacidad y habilitar opciones avanzadas en WhatsApp™ Web, como bloquear confirmaciones de lectura, ocultar el estado "en línea", restaurar mensajes borrados y descargar estados.

## Características Principales ✨
- Bloquea el envío de confirmaciones de lectura (funciona también para estados y audios).
- Oculta el estado "en línea" y las actualizaciones de "escribiendo...".
- Restaura y marca en rojo los mensajes eliminados por otros usuarios.
- Muestra desde qué tipo de dispositivo (teléfono o computadora) fue enviado cada mensaje.
- Permite descargar estados directamente con un botón.

## Instalación manual (Modo Desarrollador) 🛠️
1. Descarga este repositorio como archivo ZIP (botón verde **Code** > **Download ZIP**) y descomprímelo en una carpeta de tu computadora.
2. Abre Google Chrome y entra a: `chrome://extensions/`
3. Activa el **Modo de desarrollador** (esquina superior derecha).
4. Haz clic en **Cargar descomprimida** (esquina superior izquierda) y selecciona la carpeta de la extensión.

## Privacidad 🔒
Ningún dato personal o conversación es transmitido a servidores externos. Todo el procesamiento ocurre de manera local en tu navegador.
